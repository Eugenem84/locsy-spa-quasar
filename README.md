# Locsy — фронтенд (Vue 3 + Quasar SPA)

> Карта фотолокаций: места для съёмок, галереи снимков и фотографы,
> которые работают на этих местах.

## Стек

- **Framework:** Vue 3 + Quasar 2 (SPA, Vite)
- **Состояние:** Pinia
- **Маршрутизация:** Vue Router (hash-режим)
- **Карты:** Яндекс.Карты JS API 3 (`vue-yandex-maps`)
- **HTTP:** Axios (Sanctum: cookie + CSRF, Bearer-токен)

## Возможности

**Каталог**
- карта с подгрузкой локаций по видимой области и фильтром по категориям;
- режим «Список» с карточками и превью фото;
- выбор города с поиском по справочнику; длинные официальные названия сокращаются
  («Новосибирская обл.», «Респ Татарстан»), список держит постоянную ширину;
- карточка локации: категории, галерея, описание, избранное;
- избранное с фильтром по выбранному городу.

**Пользователи**
- регистрация с выбором роли: «ищу места» или «я фотограф»;
- профиль: аватар, город, вкладка «Материалы» (свои локации и фото со статусами
  модерации и причиной отказа), вкладка «Фотограф» (портфолио-настройки);
- добавление локации: клик по карте → форма → модерация;
- добавление фото к локации → модерация.

**Фотографы**
- страница `/photographer/:id`: портфолио, типы съёмок, контакты;
- карта «где снимает» — точки съёмок автора с переходом в локацию;
- кнопка «Скопировать ссылку на мою страницу» — для отправки клиентам.

**Модерация**
- фотографии и локации публикуются только после одобрения модератором;
- автор видит статус (на модерации / опубликовано / отклонено) и причину отказа;
- очередь модерации живёт в админке Filament на бэкенде (`/admin`).

## Маршруты

| Путь | Название | Описание |

## Запуск

```sh
npm install
npm run dev            # http://localhost:9000
npm run build          # production-сборка -> dist/spa
```

Требуется запущенный бэкенд (`locsy-laravel-backend`), доступный на том же
домене: в локальном контуре — через nginx из `docker-compose.yml` бэкенда
(`/api/` проксируется в Laravel), на сервере — через `nginx/web.conf` проекта.
Базовый URL API задан относительным (`baseURL: '/'` в `src/boot/axios.js`),
поэтому сборка не привязана к конкретному домену.

> Дев-сервер на `localhost:9000` **проксирует `/api` и `/sanctum`** на локальный
> бэкенд (`http://localhost` — сервис nginx из `locsy-laravel-backend`), см.
> `devServer.proxy` в `quasar.config.js`. Благодаря этому SPA и API живут на одном
> origin'е и cookie Sanctum работают штатно. Нужен запущенный бэкенд:
> `cd ../locsy-laravel-backend && docker compose up -d`. Если API не нужен,
> включите MSW-моки (`src/boot/msw.js`). Подробности — в
> [`docs/ENVIRONMENTS.md`](./docs/ENVIRONMENTS.md).

### Переменные окружения

`.env` в корне:

```env
# Ключ Геокодера — обратное геокодирование адресов локаций
YANDEX_MAPS_API_KEY=ваш-ключ-геокодера

# Ключ JavaScript API 3 — рисует карту (отдельный ключ!)
YANDEX_MAPS_JS_API_KEY=ваш-ключ-javascript-api
```

Это **разные** ключи: карту рисует `YANDEX_MAPS_JS_API_KEY`, а адреса подтягивает
Геокодер через `YANDEX_MAPS_API_KEY`. Оба прокидываются в бандл через
`quasar.config.js` → `build.env` (в `src/boot/yandex-maps.js` и `quasar.config.js`
есть рабочие fallback-значения, но в продакшене задайте свои ключи и ограничьте
их по домену в кабинете разработчика Яндекса: сервис «JavaScript API и Geocoder»).

После изменения `.env` перезапустите dev-сервер — значения подставляются на старте
(в dev — при запуске `quasar dev`, в prod — на этапе `quasar build`).

## Docker

```sh
docker build -t locsy-spa .
```

`Dockerfile` собирает SPA и раздаёт её через nginx (`nginx.conf`).
В полном стенде контейнер SPA поднимается из `docker-compose.yml` бэкенда
(сервис `frontend`), а внешний nginx проксирует `/api/`, `/sanctum/`,
`/storage/` и `/admin` в Laravel. На сервере обкатки тот же образ собирается
как сервис `locsy-spa` в `/opt/projects/locsy` (см. [`DEPLOY.md`](./DEPLOY.md)).

## Важное про модерацию

Фотографии попадают в публичные галереи **только со статусом «одобрено»**
(настраивается в админке: «Настройки» → модерация фотографий). Поэтому после
загрузки фото автор увидит его в разделе «Профиль → Материалы» со статусом
«На модерации», а в галерее локации — после одобрения.
